# v4.0 — Cinematic Game Day

Esta versão reúne as etapas de reforma visual e apresentação audiovisual.

## Implementado

- Tela de entrada independente do save.
- Reprodução do vídeo fornecido pelo usuário somente após interação, permitindo áudio no navegador.
- Botão de pular e tratamento de falha de reprodução.
- Dashboard com hero de franquia, logo grande, atalhos principais e núcleo de jogadores.
- Cores da franquia aplicadas de forma contextual.
- Todos os seis fundos do pacote associados a áreas coerentes da carreira.
- Navegação lateral com alvos maiores e tipografia mais legível.
- Apresentação pré-jogo com confronto e dois quintetos.
- Game Center com placar broadcast, som opcional, quadra 2.5D, movimento do jogador envolvido na posse e tela de encerramento.
- Trilha com sete músicas, seleção aleatória, controle discreto global e Configurações persistentes de volume/ativação.
- Responsividade mobile e preferência de movimento reduzido.
- Cache PWA atualizado para `vbm-cinematic-v4`.

## Compatibilidade

O build continua estático, usa base relativa e não depende de caminhos do computador. O vídeo, logos, retratos e fundos estão dentro de `public/assets` e são incluídos no pacote do GitHub Pages.
