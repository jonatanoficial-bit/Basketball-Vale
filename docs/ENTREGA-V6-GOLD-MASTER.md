# Vale Basketball Manager V6 · Gold Master

## Conteúdo e identidade

- Quatro modos de carreira com objetivos próprios: Dinastia, Reconstrução, Desafio Vale e Lenda.
- Vale Club Studio para personalizar cidade, nome, sigla, mascote, arena, cores e escudo sem romper a estrutura da liga.
- Desafios mensuráveis com recompensas, conquistas persistentes, recordes e linha do tempo histórica.
- Tutorial de primeira entrada com Mateus, personagem original negro masculino, seis etapas reais, opção de pular e reinício nas configurações.

## Camada Gold Master

- Perfil local e save integralmente funcional no GitHub Pages.
- Exportação/importação validada de save JSON.
- Cinco checkpoints automáticos e tela de restauração.
- Cloud Save real e opcional por endpoint REST HTTPS configurável; nenhum backend fictício é exibido como ativo.
- Telemetria desativada por padrão, com consentimento, fila apenas local, exportação e exclusão.
- Error Boundary com recuperação do último checkpoint.
- Alto contraste, animações reduzidas, texto ampliado, paleta distinguível e dicas para leitor de tela.
- Política de privacidade estática e registro técnico-jurídico de ativos.
- PWA e GitHub Actions para build e publicação no GitHub Pages.

## Validações executadas

- TypeScript estrito.
- Build Vite de produção.
- Auditoria Foundation.
- Auditoria de simulação de longo prazo.
- Auditoria Gold Master dos quatro modos, objetivos, desafios, conquistas e telemetria.
- Smoke test Chrome em viewport móvel 390 × 844 para tutorial, legado, Criar Clube, Gold Master e política de privacidade.

## Limite explícito

O build está tecnicamente preparado para receber licenças. A presença de logos, nomes, retratos, vídeo e músicas não substitui documentação de autorização para uso comercial. O registro completo está em `docs/GOLD-MASTER-LEGAL-ASSET-REGISTER.md`.
